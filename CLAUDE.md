# Arquivos Internos do Claude

Todo documento criado pelo Claude (tasks, planos, specs, rascunhos, notas de trabalho) vai para `.claude/`.

Subpastas padrão:
- `.claude/tasks/` — tasks e acompanhamento de trabalho em andamento
- `.claude/superpowers/plans/` — planos GSD e specs de features
- `.claude/superpowers/specs/` — specs de design e arquitetura

Nunca criar arquivos de trabalho interno na raiz, em `docs/` ou em outras pastas do repositório.
